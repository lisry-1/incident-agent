## 交付限制

- live_lab 为单服务本地 HTTP 503 注入，非生产事故、无真实数据库池；fixture 中 DB_POOL_MAX 故障不移作真实实验原因。
- 四源历史窗口、查询时 snapshot 和恢复实验结果分别描述；不能把历史异常直接当成当前状态。
- 部分 trace 被抽样；日志队列可丢弃且有计数；Jaeger 内存存储可能随重启丢失；p95 是直方图估算。
- 独立容器有严格诊断能力边界；原 Host 通用工具仍开放。可信管理员和主机不在威胁隔离证明范围。
- 模型精确整数比较与结构化输出仍不稳定。精确值以程序计算和原始证据为准；模型说明不能替代审批或恢复回执。
- 部分早期子模块文档保留当时阶段状态，最新范围以本页及根 README 为准。

这是可复现、可解释并公开失败项的本地演示版本。后续扩大评测集、接生产环境或提高模型稳定性可作为后续迭代，不阻塞当前作品集与实习投递。
